Content Refresh Opportunity Ranking for FlyRank

This paper evaluates whether an anonymized page-level content dataset can support FlyRank’s refresh lane by ranking existing pages for editorial review. The study is grounded in real content-refresh decision support: surfacing pages with stale visibility, declining demand, and engagement opportunity without leaking private signals.

The experiment compares a deterministic baseline refresh score to a client-aware random forest model. Results are reported on the same held-out client split, with the model improving precision over the baseline while keeping the output aligned to human review. The work also documents data exclusions, leakage checks, limitations, and a ranked action playbook. Reproducibility is supported through the repository notebooks and scripts.

Introduction / Problem statement

FlyRank’s refresh lane is about choosing which existing pages should be updated next, especially when editorial teams must balance effort across many candidates. This paper asks whether an anonymized page metrics dataset can support that decision by ranking pages for refresh, refresh + CTR improvement, or expansion work.

The case study is public-safe: it uses only anonymized page traffic, position, freshness, and engagement metrics, not page titles, URLs, brands, or search queries. The goal is to make the FlyRank refresh recommendation process more transparent and reviewer-friendly.

Data

This analysis uses the FlyRank ML Internship dataset from data/raw/content_refresh_anonymized.csv. The release contains anonymized page-level metrics, trailing 90-day impressions, clicks, sessions, and engagement signals. The work excluded titles, URLs, query text, and client identifiers beyond the anonymized client group used for validation. Rows lacking a valid decline label were excluded from training and validation to keep the target definition honest.

  • Release: anonymized FlyRank internship page metrics.
  • Tables: single page-level feature table and derived queues.
  • Date windows: trailing 90-day exposure and engagement metrics.
  • Exclusions: private identifiers, text fields, and unlabeled rows.

Methodology

Assumptions: the dataset’s search, freshness, and engagement metrics capture the primary signals for refresh opportunity ranking. The model should avoid information leakage by excluding any feature derived from the decline target or future performance.

  • Features: visibility (impressions, average position), freshness (days since update, content age), engagement (CTR, scroll rate, engagement rate), content depth, and categorical tiers.
  • Label: is_declining_label, a binary decline indicator embedded in the dataset.
  • Baseline: deterministic refresh score using visibility, freshness risk, position opportunity, and depth gap, with reason-code explainability.
  • Validation: client-aware holdout split so training and test clients do not overlap.
  • Leakage checks: excluded label-derived features and kept only pre-decision signals.

Results

The random forest model improves precision on the same held-out client split compared to the deterministic baseline. The model’s stronger top-K performance supports a more effective review queue while keeping the output oriented toward human intervention instead of automation.

Limitations & honest framing

This work is a reviewer aid, not an automatic publishing engine. It does not claim long-term SEO forecasting or brand strategy optimization. The dataset is limited to anonymized trailing 90-day metrics and cannot represent editorial nuance, campaign timing, or private client goals. Results may differ on new client cohorts or future traffic conditions.

Ranked recommendations

The paper’s ranked action playbook groups pages into monitor, refresh, refresh-and-review CTR, and expand-and-refresh categories. The queue is intended for human review, with clear reason codes and a conservative focus on the highest-priority items.
